Perfil Aluno — Fluxos & Funcionalidades

Todos os fluxos detalhados, incluindo anotações e caixa de recados.

📝 Área de Anotações & Recados
Novo — comunicação bilateral aluno ↔ academia
📒
Diário Pessoal (privado)
Anotações livres do aluno: como se sentiu no treino, objetivos, reflexões. Visível somente para ele.
📋
Notas por Exercício
Anotações em cada exercício: "Sinto dor no joelho nesse", "Prefiro 12kg nesse movimento". Salvo no histórico.
🏫
Recados da Academia → Aluno
A academia envia mensagens individuais (ex: "Sua avaliação está agendada para dia 10"). Aparece como notificação e fica na caixa.
✉️
Recados do Aluno → Academia
Aluno envia mensagem para a recepção/coordenação sem sair do app. Não é chat em tempo real — é mensagem assíncrona com resposta garantida em X horas.
🏷️
Avisos da Academia (broadcast)
Comunicados para todos os alunos: feriados, mudança de horário, eventos. Aparece destacado no Início.
🔔
Notificações contextuais
Lembrete de treino, confirmação de reserva, novo PR detectado, streak em risco, avaliação disponível para download.
🚨 Fluxo: Sinalização de Dor / Limitação
Segurança antes do treino — essencial para público adulto/idoso
1
Check pré-treino
Ao iniciar sessão, pergunta rápida: "Como você está hoje?" com 3 opções: Ótimo / Bem / Com alguma limitação.
2
Mapa de dores
Se sinalizar limitação: silhueta do corpo para tocar e indicar região. Selecionar tipo: dor muscular, articulação, fadiga.
3
Alerta ao Personal Flex
O Personal recebe notificação antes da sessão: "Luis sinalizou dor no joelho direito hoje." Pode adaptar o treino antes de começar.
4
Registro no histórico
Dor/limitação fica no histórico do aluno. Facilita avaliações físicas e ajustes de programa.
💪 Fluxo Completo: Iniciar & Registrar Treino
1
Tela "Meu Treino"
Mostra treino do dia (ex: 1A), # de exercícios, última vez feito, carga média anterior.
2
Check pré-treino (mood + dores)
Pergunta rápida de bem-estar. Cronômetro inicia. Tela cheia com lista de exercícios.
3
Executar exercício
Toque no exercício → vídeo autoplay, reps prescritas, campo de carga com última carga sugerida em cinza.
4
Registrar série
Teclado numérico grande. Confirmar peso + reps. Timer de descanso automático (configurável).
5
Check ✓ e próximo
Swipe ou botão para avançar. Exercícios concluídos ficam marcados com check verde.
6
Substituir exercício
Segurar → Substituir → Lista de alternativos para o mesmo grupo muscular (curada pelo Personal).
7
Finalizar treino
Botão parar → tela de resumo: tempo, volume total, exercícios concluídos.
8
Avaliação + registro
Emoji de esforço (1–6) + campo de comentário. Salvar. Se novo PR detectado → celebração 🎉.

Chat & Área de Comunidade

Comunicação interna fechada para membros da PersonalGroup. Não é rede social pública — é o espaço da família PG.

💬 Filosofia da Comunidade PG

Um ambiente fechado, seguro e moderado. O aluno se sente parte de uma comunidade boutique exclusiva — não uma rede social genérica. Foco em pertencimento, motivação coletiva e comunicação eficiente com a academia.

Personal Flex — Coach Mode

Interface otimizada para velocidade durante a sessão. Tudo em 1–2 toques, funciona offline, sincroniza com o monitor da academia.

⚠️ Contexto de uso: Personal com as mãos ocupadas, ambiente barulhento, possivelmente com suor nos dedos. Cada elemento de UI deve ter touch target ≥ 56px. Teclado numérico nativo. Nenhum campo exige digitação de texto durante a sessão.

⚡ Princípio do Coach Mode

Abrir app → Selecionar aluno (1 toque) → Treino do aluno abre automaticamente → Inserir carga + reps com teclado grande → Check ✓ → Próximo. Dados aparecem em tempo real no monitor da academia via WebSocket.

▶️ Fluxo: Executar Sessão com Aluno
1
Abrir "Sessão Ativa"
Lista de alunos do turno com foto, nome e horário. Se houver aluno com flag de dor/limitação, aparece ⚠️ vermelho ao lado do nome.
2
Ver briefing do aluno
Check pré-treino do aluno, dores sinalizadas, última sessão com notas do Personal anterior.
3
Iniciar sessão
1 toque → Treino do aluno abre. Cronômetro global inicia. Monitor da academia começa a sincronizar.
4
Inserir dados de cada exercício
Teclado numérico grande. Campos: Peso (kg) + Reps + Intensidade (opcional). Última carga sugerida em cinza.
5
Observações rápidas
Botões pré-definidos: "Boa execução" · "Aumentar carga" · "Reduzir carga" · "Dor relatada" · "Técnica a melhorar". Ou texto livre (opcional).
6
Encerrar sessão
Resumo: exercícios completos, volume, tempo. Nota do Personal para o aluno (aparece na caixa de recados dele).
🖥️ Monitor da Academia — Sync em Tempo Real
O que aparece na tela grande da academia durante a sessão
📺
Layout do monitor
Nome do aluno + foto · Exercício atual · Próximo exercício · Série em andamento · Timer de descanso · Volume acumulado.
🔄
Sync via WebSocket
Dados inseridos no app aparecem no monitor em < 1 segundo. Sem refresh manual necessário.
✅
Check visual no monitor
Quando Personal marca ✓, o exercício é riscado no monitor. Aluno acompanha visualmente o progresso.
📴
Modo offline
Se cair o Wi-Fi, dados são salvos localmente e sincronizados quando a conexão retornar. Monitor exibe "Modo offline" discretamente.

Gamificação Inteligente para Adultos & Idosos

Motivação positiva, sem pressão competitiva. Foco em consistência, bem-estar e progresso pessoal.

Princípio central: O público da PersonalGroup é majoritariamente adulto e idoso. A gamificação deve celebrar a jornada, não criar ansiedade de performance. Comparação só com si mesmo. Linguagem encorajadora. Nenhum badge humilhante por "perder" uma sequência.
🔥 Sistema de Streaks — Suave
Sequência de treinos sem punição agressiva por quebra
🔥
Streak ativo
Contador de dias consecutivos com treino. Exibido na tela Início de forma discreta, não intrusiva.
🛡️
Proteção de streak (1× por mês)
Se aluno faltar 1 dia, pode usar "escudo" para proteger a sequência. Evita frustração e abandono.
💤
Dias de descanso contam
Check-in do Wellness Day mantém o streak ativo. Descanso é parte do treino — não uma falha.
🔔
Lembrete gentil (não alarmante)
"Oi Luis! Seu streak de 5 dias continua. Que tal treinar amanhã?" — enviado com antecedência, não pressão.
📊 Progresso Pessoal — Comparação consigo mesmo
Sem ranking geral. Benchmarking apenas pessoal.
📈
"Seu melhor você"
Comparação sempre com o próprio histórico. "Você carregou 15% mais que no mês passado." Sem comparar com outros alunos.
🏆
Records Pessoais (PRs)
App detecta automaticamente novo máximo de carga. Tela de celebração aparece: "🎉 Novo recorde! 32kg no Supino."
🎯
Metas pessoais customizáveis
Aluno define: "Quero treinar 3× por semana." App acompanha e celebra quando atingido.
📅
Resumo mensal automático
"Em abril você treinou 14 dias, equivalente a 2h30 de exercícios. Parabéns! 👏" — push + card no app.

📋 Regras de UX para o Público 40+ / Idosos
✅
Celebrar toda conquista, por menor que seja
Até "você veio hoje" merece reconhecimento.
✅
Linguagem encorajadora e respeitosa
"Parabéns!", "Você está evoluindo!", nunca "Você falhou".
✅
Elementos grandes, sem hover-only
Ícones ≥ 44px, texto mínimo 15px. Tudo funciona só com toque — sem gestos complexos.
✅
Ranking opcional e nunca negativo
Se houver ranking de frequência, é positivo ("Top frequentadores") e opt-in.
🚫
Nunca punir por ausência
Streak zerado não gera mensagem de culpa. Reinicia com "Que bom que você voltou!" 🙌
🚫
Sem comparação com outros alunos
Rankings competitivos causam ansiedade e evasão em adultos mais velhos.
🚫
Sem notificações agressivas
Máximo 2 push notifications por dia. Sempre desativáveis. Horário personalizável.
🚫
Sem metas impossíveis
Metas sugeridas pelo app são moderadas (3×/semana por padrão). Aluno ajusta.

Integração de Banco de Dados & Importação de Alunos

Estratégia para migrar os dados do software atual e manter sincronização automática.

Situação atual: A academia usa um software de gestão (provavelmente Grupo Evo, Mfit, GymManager ou similar) que exporta dados em planilha. O app precisa importar esses dados E manter-se sincronizado automaticamente quando houver atualizações.
📥 Importação Inicial (Migração)
Upload único da planilha com mapeamento de colunas
1
Exportar planilha do sistema atual

O Admin exporta CSV ou XLSX do software atual (Evo, Mfit, etc.) com os dados dos alunos.

2
Upload no painel Admin do app

Admin faz upload do arquivo. O app lê e exibe pré-visualização das colunas detectadas.

3
Mapeamento de campos

Admin mapeia: "Coluna A = Nome" · "Coluna B = CPF" · "Coluna C = Plano" · "Coluna D = Vencimento" etc. Interface drag-and-drop.

4
Validação e importação

App mostra erros (email duplicado, CPF inválido) antes de importar. Admin revisa e confirma.

5
Convite automático aos alunos

App envia SMS + email de boas-vindas com link para criar senha e baixar o app.

🔄 Sincronização Contínua (Auto-update)
Manter o banco sempre atualizado sem trabalho manual
🔗
Opção 1 — Webhook/API (ideal)
Se o software atual tiver API (Evo tem), configurar webhook que avisa o app quando houver novo aluno ou atualização de plano.
📁
Opção 2 — Pasta de sync compartilhada
Software exporta planilha automaticamente para uma pasta (Google Drive / OneDrive). App monitora a pasta e reimporta quando detectar mudança.
📅
Opção 3 — Upload periódico (fallback)
Admin faz upload semanal/mensal da planilha atualizada. App faz diff e atualiza apenas o que mudou.
⚠️
Conflito de dados
Se um campo foi editado manualmente no app E na planilha, o app exibe alerta para o Admin escolher qual versão manter.
📊
Log de sincronizações
Histórico completo: data, tipo de sync, registros adicionados/atualizados/removidos. Admin pode reverter.
