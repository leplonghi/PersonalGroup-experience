# 🎨 Sistema de Cores PersonalGroup Experience (Brand Aligned)

## Filosofia de Design
Sistema de cores baseado na identidade visual oficial da **PersonalGroup**. Uma estética "Premium Wellness" que utiliza azuis profundos, ciano vibrante e tipografia moderna (Montserrat) para criar uma sensação de exclusividade e inovação tecnológica.

---

## 🌈 Paleta Principal (Official)

### Cores de Marca
```css
--pg-cobalt: #00b6fd         /* Ciano Primário - Botões, Destaques, Link */
--pg-deep-blue: #021141      /* Azul Marinho - Headers, Hero, Footer */
--pg-sky: #3363a2            /* Azul de Interação - Hover states */
```

### Bases de Interface
```css
--pg-midnight: #01081f       /* Background Dark (quase preto azulado) */
--pg-frost: #FFFFFF          /* Background Light Mode */
--pg-ice: #F8FAFC            /* Surface Light Mode */
```

### Funcionais
```css
--pg-success: #10B981        /* Verde Status */
--pg-warning: #F59E0B        /* Alerta */
--pg-surface: #FFFFFF        /* Superfície Pura */
```

---

## 🎭 Tipografia
- **Fonte Principal**: **Montserrat**
- **Estilo**: Uso intensivo de pesos `bold` (700) e `black` (900) para títulos, e `medium` (500) para corpo de texto.

---

## 🎭 Modos de Tema

### 🌞 Light Mode
- **Background**: Branco Puro / Frost
- **Texto principal**: `#021141` (Deep Blue)
- **Texto acento**: `#00b6fd` (Cyan)
- **Cards**: `rgba(255, 255, 255, 0.85)` com backdrop-blur
- **Bordas**: `rgba(2, 17, 65, 0.08)`

### 🌙 Dark Mode
- **Background**: Deep Blue / Midnight
- **Texto principal**: `#F8FAFC` (Ice)
- **Texto acento**: `#00b6fd` (Cyan)
- **Cards**: `rgba(1, 8, 31, 0.85)` com backdrop-blur
- **Bordas**: `rgba(255, 255, 255, 0.05)`

---

## 🎨 Gradientes Oficiais

### Brand Gradient

```css
linear-gradient(180deg, #00b6fd 0%, #3363a2 100%)
```

### Background Gradient (Dark)

## 🔮 Geometria (Premium Feel)
- **Cards**: `rounded-2xl` (16px) - Bordas amplas e suaves.
- **Botões**: `rounded-full` (Pill-shaped) - Como visto no site oficial.
